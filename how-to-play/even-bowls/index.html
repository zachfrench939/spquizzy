How to play Even Bowls

Even Bowls is a daily numbers puzzle. A row of numbers has to be split across the bowls so every bowl shows the same total. The board tells you that total.

Steps

  1. Tap a number. It lifts off the counter.
  2. Drop it in a bowl. Tap a bowl to drop the number in. The total under that bowl updates.
  3. Make the totals match. Use every number. Both bowls must show the same total.

Tips

  • Read the rule line first. It says the total each bowl has to reach, so you are not guessing the target.
  • Tap a number that is already in a bowl if you want to pick it up and move it.
  • Every number is used once. An empty bowl at the end means a number is still on the counter or in the wrong bowl.
  • The puzzle is the same for everyone on your local date. This page does not list today's numbers.
