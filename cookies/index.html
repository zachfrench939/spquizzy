Spiquizzy

Cookies

Last updated 11 November 2026.

The game does not set a cookie. Sign-in, if you use it, keeps a session token in localStorage. Optional analytics run only after Accept, and they do not use a cookie.

localStorage

  • spquizzy.consent — Accept or Reject.
  • spquizzy.drop.run — today’s official run, so a refresh can resume.
  • spquizzy.drop.bank — guest bank and day history.
  • spquizzy.drop.howto — you have closed How to play.
  • spquizzy.drop.settings — sound and reduce motion.
  • spquizzy.drop.session — sign-in token, if you asked for one.

Clear local data lives in Settings. See also Privacy.

Optional analytics stay off until you agree. Reject is the same size as Accept.
